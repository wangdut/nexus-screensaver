## 核验结论的范围

已核对的是**播出机构、节目设置、频道身份及公开直播源的对应关系**。本白名单是项目维护的收录清单，不是监管部门对 NEXUS 的认证，也不能担保第三方未来每一段直播内容、广告或音乐的权利状态。

NEXUS 作为本机播放器直接请求官方直播源，不转存、录制、重新分发或提供音频代理；安装包不含广播录音。官方公开可访问、CORS 允许访问都不等于授予第三方商业转播权。本项目未取得或宣称取得电台的商业转播、再分发或音乐作品版权授权；如改变为商业转播或音频分发服务，应另外取得相应授权并核对适用许可要求。

没有进入首批名单的电台，表示本次未完成足够的来源核验或技术验证，**不表示被判定为非法**。例如央广音乐之声、经典音乐广播可在总局名录中找到，但本版不接入需要另行处理的动态音源；北京音乐广播本次未能访问其官网完成音源交叉核对，也未收录。

## 程序如何执行限制

- config/radio-allowlist.json 是唯一目录来源，构建时同时打入网页播放器和 Windows 程序，运行时不接受远程目录扩充。
- 用户保存的数据只用于识别频道。名称、直播 URL、HLS 标记始终由本版白名单提供，修改收藏中的 URL 不会改换音源。
- 已知的旧“江苏经典流行音乐广播”目录 ID 会迁移到官方源。其他未收录的历史电台从可播放收藏和上次选择中移除，音量、静音及其他偏好保留；旧开放目录缓存删除。
- 搜索离线可用，仅匹配白名单的名称、频率和关键词。无结果时不退回开放搜索。
- 重连最多两次，只使用相同白名单音源。源变化需要重新核验后随新版发布，不自动接受其他域名或节目。
- HLS 清单和分片逐次检查同一频道的 HTTPS 来源及路径；拒绝 HTTP 跳转、跨源重定向、其他频道路径和未知资源。网页 CSP 与 Windows 网络请求检查提供额外限制。

本机文件被人为改写后不属于受验证的发布包；SHA-256 和文件清单用于发现包损坏，不等于代码签名。

## 后续维护

增加或变更电台前，维护者需核对最新主管部门名录及变更公告、官方频道页、直播配置和实际音源；记录核验日期、来源、机构、许可证编号及频道映射。地址失效、频道撤销、权利人提出异议或证据不足时应暂停收录。不能仅凭中文名称、country=CN、HTTPS、ICP备案或可播放状态加入白名单。

修改清单后必须运行目录边界测试、旧收藏迁移测试、Windows 原生播放测试及安装/更新回归，再发布新版。查阅最新官方资料是每次目录更新的人工步骤，程序不将旧核验结果包装成实时法律认证。

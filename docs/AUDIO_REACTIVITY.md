# 音乐律动 · 实现与验证

NEXUS 1.4.0 将实际声音的频谱、响度和瞬态映射到现有粒子场景。右上角 **≋** 可选择内置电台、电脑声音或关闭，并调整 0–150% 强度；默认跟随内置电台，首次不会自行播放音乐或采集电脑声音。

## 两种音源

| 音源 | 信号路径 | 使用方式 |
|---|---|---|
| 内置电台 | 当前播放器 → captureStream → Web Audio AnalyserNode | 在 ♫ 中选择已核验电台即可；换台及重连自动绑定新播放器 |
| 电脑声音 | Windows 默认播放设备 → WASAPI shared-mode loopback → 本机 FFT | 选择「电脑声音」，再用音乐软件或浏览器播放音乐 |

电台分析是旁路读取，原 Audio 元素继续负责扬声器播放，分析分支不接扬声器，不产生双重播放。播放器音量用于调整测得能量，静音/停止时输入归零。分析失败时显示状态，不调用停止电台或更换音源。

电脑声音模式采集默认播放设备的混合输出，因此音乐、网页视频及通知声都可能影响画面。不是麦克风输入，也不按软件识别节目。多窗口共用一个引用计数管理的采集线程，最后一个窗口释放时停止；主屏电台频谱通过原生宿主传给副屏，副屏不播放重复声音。

默认播放设备变化每秒检查一次；设备不可用、拔出或音频服务异常时清空输入、显示状态并自动重试。应用不改变用户的音频设备、系统音量或其他软件设置。使用专门指定的非默认输出设备、独占模式或受保护音频时，可能获取不到该声音；请将播放器输出与 Windows 默认播放设备保持一致。纯浏览器预览只支持电台分析，电脑声音需要 Windows 程序。

## 信号与视觉

- 2048 点频谱，32 个对数频带，展示范围 40 Hz–16 kHz；超过设备奈奎斯特频率的频带置零。实际频率分辨率取决于采样率，48 kHz 时约为 23.4 Hz。
- Windows 使用 Hann 窗 FFT，支持 float32 及 PCM16/24/32；先计算各声道频谱功率再合并，避免反相立体声相加后变成零。浏览器使用 Web Audio 内置分析器，两者共享后续特征处理。
- RMS 衡量实际能量；正向频谱变化检测瞬态，带自适应阈值与 240 ms 间隔，不按定时器伪造节拍。它不是 BPM 或歌曲音符识别器。
- 输入约 25 次/秒，渲染使用平滑包络；超过 350 ms 没有新信号时开始回落。原始 PCM 仅在采集线程的内存窗口中短暂存在，跨 WebView 传递的是 32 个频带与能量，原始音频不落盘、不上传。
- 量子星核：低频径向舒展，中频塑造表面纹理，三条频谱光带环绕。
- 引力星环：低频推动轨道，真实瞬态形成向外传播的波，高频点亮细节。
- 时空之门：频带改变环带半径与纵深，形成随旋律变化的光纹。
- 光带与粒子共用场景变换、调色板、场景过渡及镜头；没有音乐时附加光带消退，原来的星空继续演化。

## 生命周期与偏好

音源和强度保存在 WebView 本地偏好 `nexus.rhythm.v1`，与现有偏好一起随升级保留，同源窗口实时同步。关闭律动不停止音乐。画面暂停、最小化、页面隐藏、显卡上下文丢失或窗口退出时释放相应分析资源；系统嵌入式小预览不采集。系统的「减少动态效果」沿用默认暂停，可由用户主动继续。节能模式沿用 30 FPS、16,000 粒子及关闭辉光。

## 验证方式

以下命令在项目目录执行。先 `npm.cmd run build`，浏览器测试另外保持 `npm.cmd run dev` 运行。

```powershell
node tests/rhythm-signal.mjs
powershell -ExecutionPolicy Bypass -File tests/spectrum.ps1
powershell -ExecutionPolicy Bypass -File tests/spectrum.ps1 -Live
node tests/rhythm.cjs
powershell -ExecutionPolicy Bypass -File tests/native-rhythm.ps1
powershell -ExecutionPolicy Bypass -File tests/native-audio.ps1
```

`-Live` 与原生律动测试会用独立测试播放器发出短时低音量测试信号；电台回归中也有短时取消静音，以验证真实广播频谱。测试使用隔离的配置目录和注册表，不改用户音频设备或音量。

自动检查覆盖已知频率、反相声道、持续音不伪造重复节拍、瞬态、静音、过期输入、暂停/恢复、关闭后继续播放、实际 Windows 回环与 WebView 消息链路、多窗口同步及副屏频谱转发。浏览器截图由确定性 PCM 测试信号驱动，并检查 320px 至 4K 的布局。设备不可用通知使用桥接故障注入检查；物理拔插、多种 USB/蓝牙/HDMI 设备和多台物理屏幕仍需在对应硬件实测。

电台收录继续遵守 [国内音乐电台白名单](RADIO_ALLOWLIST.md)。电脑声音模式只对用户本机已有播放做可视化，不新增电台目录或音源，不提供广播录制与分发。

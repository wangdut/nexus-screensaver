# NEXUS · 星核实验室 1.4.0

Windows 10 / 11 x64 交互式粒子屏保。包含量子星核、引力星环、时空之门，支持真实音乐律动、通知区域托盘、系统偏好设置和中文音乐电台。视觉效果离线可用，电台按需联网。

## 安装与首次使用

1. 完整解压 NEXUS-Windows-x64-v1.4.zip。
2. 双击 Install.cmd，为当前用户安装，无需管理员权限。默认启用 Windows 屏保，闲置 5 分钟后全屏。
3. 在自动打开的偏好设置中调整闲置时间（1–240 分钟），按需勾选登录 Windows 时启动托盘，点击保存。
4. 右键右下角通知区域的 NEXUS 图标进入设置，也可从开始菜单打开 NEXUS 偏好设置。图标可能收在 Windows 隐藏图标区域。
5. 窗口右上角 ♫ 选择音乐电台。首次默认关闭音乐，可收藏、搜索、调音量及静音。

只体验画面：双击 Nexus.exe 或 Launch.cmd，不会自动安装、启用开机启动或更改系统屏保。请保留旁边的 web 文件夹和 DLL，不能只复制 exe 或 scr。

运行环境：Windows 10 / 11 x64、.NET Framework 4.8、Microsoft Edge WebView2 Runtime、支持 WebGL 2 的显卡。不需要 Node.js 或 .NET SDK。WebView2 缺失时可从微软官网下载：https://developer.microsoft.com/microsoft-edge/webview2/

## 开机启动与闲置全屏

双击一次不会自动开启开机启动。安装后勾选「登录 Windows 时启动托盘」，才会在登录后自动显示托盘；不会自动打开画面或播放音乐。

Windows 系统屏保独立于托盘运行。安装并启用后，重启也不用再双击，达到闲置时间由 Windows 启动全屏。退出托盘不会停用系统屏保；取消「启用 NEXUS 系统屏保」才会关闭闲置触发。

可选：覆盖全部显示器、纯净模式、移动鼠标或按键即退出的传统模式、关闭体验窗口后保留托盘。默认支持鼠标/触摸互动，Esc 退出；纯净模式下 H 显示控件。关闭体验窗口会停止该窗口的音乐。

锁屏、屏幕关闭、休眠及组织策略由 Windows 管理。如果系统要求恢复时显示登录屏幕，首次输入可能直接返回登录界面。完整互动也可以在窗口体验版按 F 全屏使用。程序不修改锁屏策略，不替代安全锁屏。

## 卸载与升级

v1.2 起，设置页顶部显示当前版本并检查 GitHub 正式版（同一进程缓存六小时，手动检查可刷新）。发现新版可「忽略此版」或「立即更新」，不操作不影响功能。安装版下载校验完成后自动重启；便携版打开下载页。v1.1 首次升级到 v1.2 需手动运行新版 Install.cmd。

新安装先校验文件清单，将程序准备到 App.new，再整体切换 App。真实启动检查成功后删除 App.previous 及废弃文件，失败回退。注册表偏好及同级 WebView 数据保留；1.3.0 首次打开播放器时会清理白名单外的历史电台，音量和其他偏好不变。更新下载任务结束后清理；异常中断留下的下载任务在下次更新准备时清理（超过一天）。不会清理用户自行下载的 ZIP 或其他文件。

GitHub 超时、下载失败、校验不符或取消时保持当前程序运行。更新不使用第三方镜像；SHA-256 验证完整性，不等同于代码签名。

体验和设置窗口采用协调的原生深色标题栏，保留系统拖动、贴边、缩放及关闭按钮。Windows 11 支持精确标题栏颜色和隐藏边框线，Windows 10 使用系统支持的深色回退。全屏继续无标题栏。

安装后，可通过「控制面板 → 程序和功能」或「设置 → 应用 → 已安装的应用」卸载 NEXUS，也可双击 Uninstall.cmd。卸载移除应用、启动项及快捷方式；若当前屏保仍为 NEXUS，则恢复安装前的屏保设置。保留收藏、音量与视觉偏好，便于重新安装。

升级时完整解压新包并运行 Install.cmd。保留现有闲置时间、屏保启用状态与偏好。应用位于 %LOCALAPPDATA%\NexusScreensaver\App，WebView 用户数据位于同级 WebView 文件夹。

1.3.0 起使用本机内置的中国大陆持牌音乐频率白名单，不再查询 Radio Browser 开放目录。首批仅收录：

| 电台 | 频率 | 播出机构 |
|---|---|---|
| 江苏经典流行音乐广播 | FM97.5 | 江苏人民广播电台 |
| 江苏音乐广播 | FM89.7 | 江苏人民广播电台 |

2026-10-17 核对了国家广播电视总局名录中的机构许可证 1210001、节目设置和江苏广播网的官方音源对应关系。完整依据见随包《电台白名单说明.md》，或仓库 https://github.com/wangdut/nexus-screensaver/blob/main/docs/RADIO_ALLOWLIST.md 。

- 搜索名称、频率或关键词，仅返回上述名单；断网也可搜索。没有匹配结果时不接入开放目录，不支持自定义地址。
- 播放/停止、音量、静音/取消静音；M 快速切换静音。纯净模式仍有迷你播放器。
- 如需屏保自动播放，先选择电台，再勾选「屏保启动时播放上次电台」。保留音量和静音状态。
- 仅主显示器播放；同一用户的另一个 NEXUS 窗口已播放时，提示先停止，避免叠音。Windows 小预览不播放。
- 收听需要联网，直接请求官方 HTTPS HLS 音源。程序限制每次清单和分片请求的来源、路径，并拒绝重定向；不会使用第三方转载链接或自动切到其他节目。
- 连接失败最多重试两次，可手动重试或换台。官方服务也可能临时中断，广播可能包含主持和广告。

升级后，已识别的旧江苏经典流行音乐广播收藏会迁移到官方源，其他未核验的收藏及上次选择被移除，页面会提示重新选择。音量、静音和其他偏好保留；旧开放目录缓存清除。若上次电台已移除，即使自动播放开关开启，也不会擅自选择其他电台。

白名单核验的是频道资质和官方来源，不是监管部门对本软件的认证，不担保未来每段直播内容，也不代表项目取得商业转播、再分发或音乐版权授权。未收录不表示电台非法。NEXUS 不录制、转存、代理或重新分发广播，安装包不附带广播录音；不再请求开放目录或发送电台点击统计。

## 音乐律动

1. 在体验画面右上角点击 **≋**；纯净模式先按 **H** 显示控件。
2. 选择「内置电台」：再从 **♫** 播放白名单电台，粒子和光带会跟随真实声音。默认已选择此音源，但不会自行播放电台。
3. 选择「电脑声音」：用其他音乐软件或浏览器播放音乐，NEXUS 读取 Windows 默认播放设备的输出。扬声器、耳机均可，播放器应使用相同的默认输出设备。
4. 根据喜好调整 0–150% 强度，默认 80%。频谱面板显示实际信号，设置自动保存。选择「关闭律动」只关闭共振效果，不停止播放。

低音让星核舒展，旋律编织环绕光带，节拍在星环上推出波纹，高频点亮细节。没有声音时附加效果自然消退，原来的粒子动画继续演化。暂停画面、最小化或退出会释放分析资源，恢复后重新连接。默认设备切换或断开后会自动重试，状态显示在律动面板中。

电脑声音只在本机实时分析，不录音、不上传、不使用麦克风；系统通知等混合输出也可能产生律动。多屏共享音频分析，主屏电台不会在副屏重复播放。系统小预览不采集；启用系统「减少动态效果」时默认暂停，可手动继续。

若面板一直没有信号，请确认播放器没有静音、正在输出到 Windows 默认播放设备。专门指定到其他设备、独占播放或受保护的音频可能无法捕获。网页开发预览不提供电脑声音采集，请使用 Windows 程序；需要浏览器授权手势时面板会显示「启用分析」。

技术与验证记录：https://github.com/wangdut/nexus-screensaver/blob/main/docs/AUDIO_REACTIVITY.md 。

## 交互与屏幕适配

| 操作 | 效果 |
|---|---|
| 移动鼠标 / 手指 | 局部引力扰动 |
| 按住再释放 | 聚拢星尘，释放能量波 |
| 拖动 / 触摸滑动 | 旋转观察角度 |
| 1 / 2 / 3 | 星核 / 星环 / 时空之门 |
| 空格 | 暂停或继续演化 |
| H | 隐藏或显示控制界面 |
| F | 窗口体验版切换全屏 |
| M | 静音或取消静音 |
| ? | 操作指南 |
| Esc | 关闭弹窗、退出全屏或退出屏保 |

引力、速度、光谱、画质和自动漫游在本机保存。自动漫游每 75 秒切换形态。精细模式最多 30,000 个动态粒子，节能模式 16,000 个并关闭辉光；自动画质持续低帧率时降低负载。窗口隐藏时停止渲染，减少动态效果偏好默认暂停，可手动继续。

画面按视口和像素比重新构图，控制区适配窄屏。已检查常规宽屏、4K、超宽屏、竖屏和 320px 窄屏；多台物理显示器及不同显卡仍需在对应硬件验证。Windows 配置入口 /c、全屏 /s 和嵌入预览 /p HWND 均支持。

## 开发与验证

所有命令在本项目目录执行：

    npm.cmd ci
    npm.cmd run build
    npm.cmd run dev

另一个终端运行网页验证：

    npm.cmd test
    node tests/radio.cjs
    node tests/radio-policy.cjs
    node tests/radio-recovery.cjs

Windows 原生验证：

    powershell -NoProfile -ExecutionPolicy Bypass -File tests/native.ps1
    powershell -NoProfile -ExecutionPolicy Bypass -File tests/tray.ps1
    powershell -NoProfile -ExecutionPolicy Bypass -File tests/settings.ps1
    powershell -NoProfile -ExecutionPolicy Bypass -File tests/installer.ps1
    powershell -NoProfile -ExecutionPolicy Bypass -File tests/native-audio.ps1
    dist/Nexus.exe --radio-smoke

构建使用 Windows 自带 .NET Framework C# 编译器；首次构建下载固定版本 WebView2 SDK。前端依赖本地打包，许可证在 licenses。安装与设置验证使用独立注册表分支，不更改实际桌面设置；音频回归包含短时低音量测试信号和取消电台静音，以验证真实频谱。

生成干净发布包：powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1。发布脚本使用文件白名单，排除测试日志、截图和浏览器测试配置。

包内复验：powershell -NoProfile -ExecutionPolicy Bypass -File tests/release.ps1。检查归档清单与版本，解压后启动真实 Windows 程序验证渲染。

源码：web 为粒子/电台界面，src 为 Windows 宿主，scripts 为构建/安装/打包，tests 为验证。更新说明见 RELEASE-NOTES.md。程序不启用麦克风或摄像头。
